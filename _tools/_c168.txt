## C-168 — 2026-09-24 — ★**同一字段名在两个修订下是两个量**：旧产物的
## `n_where_leq_differs_from_gt = 294` **不是**「≤t0 与 >t0 不同」的计数；
## ★**修订表缺了正在跑的那一版**——表上最靠下的一行不是现役；
## ★「重跑跑哪一版」**由测量判定**（mtime 早于进程启动 66 s ＋ 字节相符）

### ① 语义漂移（同侪撤回其 294＋6 假设，**撤回方向对它自己不利**）

现役写入器 `:684-688` 自述：
「**THE CONTROL THE NAME PROMISES**：`<= t0` 的重算是否与 `> t0` 的不同？**彼此相比**。
**上一版把 `stored` 与 `gt` 重算相比，并把那个计数用这个名字返回，所以它根本不是惰性控制**
——而一个 stored 里带着未来窗口的行**两个分支都不计**，于是永远看不见。See C-159。」

⇒ 旧产物里 **294 = `stored == by_le[False]` 的行数**；**6 = `n_mismatch` = `stored != leq` 的行数**。
**两个计数打的是两个不同的比较目标** ⇒ **294 + 6 = 300 不含任何集合信息。**
**★同侪据此撤回自己的假设。登记为撤回。**

**★而旧产物的 `note` 字段仍写着旧语义**：
「`gt` counts edges with step > t0 and must DIFFER, otherwise the filter is inert
and the equality above would prove nothing.」
⇒ **读该产物的人被告知了一个产出它的修订并未计算的含义。**
**⇒ 这是 C-161 / C-165② 的一族：字段名、note、被计算的量，三者不一致。**
且**同一字段名在两个修订下是两个量，只能靠修订区分**——
**「同名不同物」落到了 JSON 字段上**，而不只是落到文件上。

### ② 修订表缺了正在跑的那一版

`_tools/_revisions/README.md` 的**写入器**表原有两行：

| 行 | 是什么 |
|---|---|
| pod `55d7d8f8`（72,392 B） | **产出旧产物**者；有 ACT 修复，**无** within-t0 增补；同带两个 C-159 缺陷 |
| local `6698953db9`（77,127 B） | pre-fix；有 ACT 修复＋within-t0 增补；**同带**两个 C-159 缺陷 |

**而现役 `1ebf15e8`（79,168 B，含 C-159 自环修复）无行。**
⇒ **表上最靠下的一行不是现役**；据表解读重跑的 `n_exact_match`
**会预测出那六处不匹配**，而现役的 `i_sl` 修法正是为消除它。
**⇒ 该表会对一个正在运行的文件预测出它并不具备的失败。**

**修**：把 `1ebf15e8` **在它还是现役时**存入 `_tools/_revisions/`（另存副本、断言 sha），
补一行并加注说明「**`local, pre-fix` 那一行不是现役，而它是读者会停下的那一行**」。
**★纪律：产出了一次测量的修订，必须在下次编辑之前存档**——
否则该测量在它自己的代码路径上不可读（正是该 README 开篇那句话）。

### ③ ★「重跑跑的是哪一版」：**由测量判定，不是 mtime 推断**

pod 文件 `mtime = 2026-09-24 03:33:48Z`，进程 `lstart = 03:34:54Z`（**早 66 秒**），
`size = 79,168`，`sha = 1ebf15e8…`
⇒ **文件在进程启动之前就已是这些字节，且此后未被写过 ⇒ 进程读的就是这些字节。**

**这是包含关系（containment），不是时间戳巧合。**
（同侪称此点「只能从 mtime 推断、无法判定」——**可以判定，且已判**。）
**⇒ 结论：重跑运行的是含 C-159 自环修复的修订；`feature_filter_verification_exact`
预期为 True 的预测（C-167 §④）成立。**

### ④ 路径前缀第三次不准

同侪给的 `_revisions/README.md` 实为 **`_tools/_revisions/README.md`**（**按内容检索**才定位）。
**这是同族第三次**（`_ceiling_check.py` 缺前导下划线 / `tools/` vs `_tools/` / 本次）。
⇒ **名字里的每一段（目录、文件名、扩展名）都要按内容回核，不能只核一段。**
