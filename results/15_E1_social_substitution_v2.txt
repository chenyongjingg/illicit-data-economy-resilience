  panel: 174 sellers x 32 weeks = 5568 rows

  (i) seller + week FE           : beta=-0.0639 se=3.2940 t=-0.02 p=0.9846
  (ii) + stratum x week FE       : beta=+1.1110 se=3.5213 t=0.32 p=0.7528

  (ii) is the model that matters. It lets each baseline-intensity group
  follow its own weekly path, so a differential trend that is merely a
  function of baseline size -- the thing that produced v1's apparent
  effect -- is absorbed rather than attributed to the shock.

  If any placebo is comparable in size to the event estimate, model (ii)
  has not fixed the problem and E1 declines the claim.
